## 開闢（かいびゃく）2.0.0 — MDカード画像ツール

遊戯王 マスターデュエル（MD）のスクリーンショットからカード画像を切り抜いて、カード名で保存する Windows 向けの非公式ツールです。2.0.0 は画面を一新しました。旧アプリ（Python版 v1.4.1）より処理が速く、アプリ本体も軽量です。

### 使い方

1. `mdript-v2.0.0-windows-x64.zip` をダウンロードして展開します。
2. `mdript.exe` をダブルクリックします。インストーラはありません。
3. 画像かフォルダをウィンドウへドロップします。

WebView2 Runtime が必要です。多くの環境では導入済みです。起動しないときは Microsoft の Evergreen Standalone Installer を入れてください。動作を確認した環境は Windows 11 です。

exeにコード署名はないため、Windows の警告が出る場合があります。`SHA256SUMS.txt` と照合できます。

### 特長

- 画像・フォルダのドラッグ＆ドロップによる一括処理。
- サムネイル付きの結果一覧と、「確定」「要確認」「カードなし」「エラー」での絞り込み。
- 「要確認」「カードなし」の画像は、カード名・IDで検索して照合データへ登録し、処理し直せます。
- 処理や更新の途中でウィンドウを閉じても、画像の保存とログの記録が終わってから閉じます。
- ログ（`log.csv`）や設定を保存できなかったときは、画面でお知らせします。
- 公式データベースからカード名と新しいカードセットの照合データを取得できます。

### 旧アプリからの移行

初回起動時に、旧アプリ（`%APPDATA%\mdript`）の設定・カード名・登録データを、新しい保存先（`%APPDATA%\mdript-v2`）へコピーします。旧アプリのフォルダは変更しません。旧アプリへはそのまま戻れます。

### v2.0.0-beta.1 からの主な変更

- アプリ名を「開闢 — MDカード画像ツール」にし、タイトルに版番号を表示します。
- 一覧の「距離」を表示しません。名前候補は画像に近い順に順位を表示します。
- 「英語版」の選択肢を「区別しない」に、形式の「both」を「両方」にしました。
- 解像度の設定を廃止しました。カードの位置は自動で見つけます。
- 設定を保存できなかったときの通知を追加しました。

### 既知の制限

- 「確定」でも誤判定の可能性があります。似たカードや位置がずれた画像は目視で確認してください。
- ウィンドウ表示やゲームのUI変更で、カードの位置の検出が外れることがあります。
- 動作を確認した環境は Windows 11 です。
