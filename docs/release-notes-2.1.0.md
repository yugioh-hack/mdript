# 開闢 2.1.0

- 英語名データがない旧版のカード名データを検知し、日本語名・英語名の再取得を案内します。
- 画面に英語名の件数を表示します。
- 英語名の取得に失敗した場合や取得結果が空の場合は、更新失敗を通知し、既存のカード名データを保持します。
- 日英の画像を混ぜ、WebP形式・「英語名で保存」・「ja と en に分ける」で処理した場合の保存名をテストで確認しました。
- 配布用実行ファイルに画面を内蔵し、開発サーバーなしで起動できます。

英語版が日本語名で保存される場合は「カードデータ更新」→「カード名を取得」を実行してから画像を再処理してください。設定・登録済みの照合データは引き継がれます。

## インストール・更新

`mdript-v2.1.0-windows-x64.zip` を展開し、`mdript.exe` を起動してください。Windows用です。WebView2 Runtimeが必要です。

アプリを終了してから実行ファイルを入れ替えてください。設定・カード名・登録済みデータは `%APPDATA%\mdript-v2` に残ります。同梱の `SHA256SUMS.txt` で配布ファイルのハッシュを照合できます。
